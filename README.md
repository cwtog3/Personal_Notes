# Персонализированные заметки

## О проекте

«Дневник рефлексии» - учебный веб-проект, который помогает регулярно вести дневник
и осмыслять события дня.

Главная идея: человеку сложно писать в дневник, когда непонятно, с чего начать.
Сайт предлагает вопрос дня, на который хочется ответить. Ответ сохраняется как заметка,
а затем его можно искать, фильтровать по тегам, сортировать и удалять.

## Статус проекта

Реализован **интерактивный фронтенд (ЛР2)**:

- SPA с единым объектом состояния `state`;
- поиск, фильтрация по тегам и сортировка заметок;
- удаление заметок через делегирование событий;
- сохранение данных в `localStorage`;
- перерисовка интерфейса через `render()`.

Backend, база данных, авторизация и автоматическая генерация вопросов пока не реализованы -
это следующие этапы развития проекта.

## Что изменилось по сравнению с ЛР1

- статический HTML/CSS-макет превращён в SPA с состоянием;
- добавлена вся интерактивная логика на Vanilla JS (`js/app.js`);
- данные сохраняются в `localStorage` и восстанавливаются после перезагрузки;
- добавлены поиск, фильтрация, сортировка, модальное окно и валидация;
- удаление реализовано через делегирование событий;
- интерфейс строится по принципу `UI = render(state)`.

## Реализованные возможности

### 1. Динамический поиск
- Поле `#query` (`<input type="search">`).
- Поиск по тексту и вопросу заметки, регистр не важен (`toLowerCase()`).
- Состояние поиска хранится в `state.searchQuery`.

### 2. Фильтрация по тегам
- Выпадающий список тегов с чекбоксами (`#tags-dropdown`).
- Теги собираются из всех заметок функцией `getAllTags()`.
- Выбранные теги хранятся в `state.selectedTags`; активна логика «ИЛИ».
- Есть сброс фильтра (пункт «Все теги» / пустой `selectedTags`).

### 3. Сортировка
- Селект `#sort-by` с вариантами `date-asc` и `date-desc`.
- Режим хранится в `state.sortBy`.
- Сортировка иммутабельная: `filter()` возвращает новый массив, `sort()` не мутирует `state.notes`.

### 4. Удаление заметки (Event Delegation)
- Кнопка «Удалить» на каждой карточке.
- Один слушатель `click` на контейнере `.my-notes`, поиск цели через `e.target.closest(".delete-note")`.
- После удаления состояние и `localStorage` обновляются, вызывается `render()`.

### 5. Сохранение в localStorage
- Ключ `notes`.
- Сериализация/десериализация: `JSON.stringify()` / `JSON.parse()`.
- При пустом хранилище загружается массив демонстрационных заметок (`defaultNotes`).
- Данные сохраняются при добавлении и удалении заметки.

### 6. State-Driven UI
Единый объект состояния:

```javascript
const state = {
    notes: [],
    searchQuery: "",
    selectedTags: [],
    sortBy: "date-desc"
};
```
