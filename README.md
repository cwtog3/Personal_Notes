# Дневник рефлексии

## О проекте

«Дневник рефлексии» — учебный веб-проект, который помогает регулярно вести дневник и осмыслять события дня.

Главная идея: человеку сложно писать в дневник, когда непонятно, с чего начать. Сайт предлагает персональный вопрос дня, на который хочется ответить. Ответ сохраняется как заметка, а затем его можно просматривать, искать по темам и анализировать в статистике.

Проект ориентирован на людей, которые хотят рефлексировать регулярно, но нуждаются в понятной отправной точке.

## Статус проекта

Сейчас реализован **фронтенд-прототип**:

- свёрстана главная страница;
- есть страница со списком заметок;
- добавлены поиск и фильтр по темам;
- настроена адаптивная вёрстка;
- подготовлена заготовка страницы статистики.

Backend, база данных, авторизация и автоматическая генерация вопросов пока не реализованы. Это следующие этапы развития проекта.

## Возможности

### Уже реализовано

- **Главная страница**
  - вопрос дня;
  - поле для ответа;
  - кнопка «Сохранить»;
  - блок «Последние заметки».

- **Боковое меню**
  - открывается по кнопке;
  - содержит ссылки на основные разделы.

- **Страница «Мои заметки»**
  - форма поиска по тексту;
  - фильтр по теме;
  - карточки записей с датой, вопросом дня, ответом, изображением, настроением и тегом.

- **Адаптивность**
  - на ширине до `1280px` панель статистики скрывается;
  - макет подстраивается под узкие экраны.

- **Семантическая разметка**
  - используются `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.

### Планируется

- генерация персонализированных вопросов для рефлексии;
- сохранение записей на сервере;
- авторизация пользователей;
- статистика по настроению, тегам и регулярности записей;
- экспорт заметок в Markdown / Obsidian;
- база данных для хранения пользователей и заметок.

## Технологии

- **HTML5** — семантическая разметка.
- **CSS3** — оформление в отдельном файле `styles/main.css`.
- **Flexbox** — для боковой панели, центрального блока и формы.
- **CSS Grid** — для сетки заметок `.my-notes`.
- **Media queries** — адаптация под разные ширины экрана.
- **Google Fonts** — шрифты `Kudry` и `Lora`.
- **Класс `visually-hidden`** — скрытие элементов, которые должны оставаться доступными для вспомогательных технологий.

JavaScript и backend пока не используются: проект работает как статический прототип.

## Доступность

В проекте уже заложены базовые принципы доступности:

- у документа указан язык `lang="ru"`;
- у полей формы есть `label`, связанные через `for` и `id`;
- для скрытых подписей используется класс `visually-hidden`;
- изображения имеют атрибут `alt`;
- навигация построена на ссылках, а не на `div`;
- интерактивные элементы представлены тегами `a`, `button`, `input`, `textarea`, `select`.

В дальнейшем планируется:

- улучшить тексты `alt`, чтобы они точнее описывали смысл изображений;
- добавить видимый фокус для клавиатурной навигации;
- проверить контрастность цветов;
- дополнить страницу статистики доступными элементами.

## Как открыть

1. Скачать репозиторий.
2. Открыть файл `index.html` в браузере.
3. Переходить между страницами через боковое меню.

Дополнительный сервер для запуска текущей версии не требуется.

## Проверка

Проект проверялся по следующим пунктам:

- HTML проходит проверку валидатором W3C;
- страницы проверены на ширине `360`, `768` и `1280px`;
- горизонтальная прокрутка отсутствует;
- карточки заметок перестраиваются в одну или несколько колонок;
- ссылки и изображения работают.
