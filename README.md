# Дневник рефлексии

## О проекте

Сайт с персонализированными вопросами для ведения дневника. Проблема, которую он решает: вести дневник полезно, но сложно - непонятно, что писать. Сайт каждый день предлагает персональный вопрос, на который хочется ответить. Записи можно вести прямо на сайте или экспортировать в Obsidian.

Проект предназначен для людей, которые хотят рефлексировать регулярно, но не знают, с чего начать.

## Структура проекта
- `frontend/index.html` — главная страница
- `frontend/styles/main.css` — стили
- `frontend/images/` — изображения
- `README.md` — описание проекта

## Основные блоки страницы

1. **Шапка** - название проекта и навигация по разделам: «Записи», «Поиск», «О проекте».
2. **Главный заголовок** - `h1` «Заметки» и короткое описание проекта.
3. **Коллекция карточек** - 6 записей дневника. Каждая карточка - `<article>` с датой, вопросом дня, выдержкой из записи, изображением и двумя свойствами: настроением и тегом.
4. **Форма поиска** - `<form>` с двумя полями разных типов: `input type="search"` и `select` (фильтр по теме), с `label`, `for`, `id`, `name` и кнопкой `submit`.
5. **Блок «О проекте»** - описание того, как работает сайт.
6. **Подвал** - название проекта, год, ссылка на репозиторий.

## Использованные технологии

- **HTML** - семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `footer`.
- **CSS** - стили в отдельном файле `styles/main.css`, подключены через `<link>`.
- **Flexbox** - для шапки (`header`, `nav`) и формы. Это одномерные раскладки.
- **CSS Grid** - для сетки карточек (`#records`): `repeat(auto-fit, minmax(280px, 1fr))`. Карточки автоматически перестраиваются в 1, 2 или 3 колонки.
- **CSS-переменные** - цвета, отступы и скругления заданы в `:root`.
- **Media queries** - на 768 и 1100 px для адаптивности.
- **`:focus-visible`** - видимая рамка фокуса для всех интерактивных элементов.

## Доступность

- У всех изображений есть `alt`.
- У всех полей формы есть `label`, связанный через `for`/`id`.
- Ссылки в навигации ведут на реальные разделы страницы (`#records`, `#search`, `#about`), а не на `href="#"`.
- Интерактивные элементы — `<a>` и `<button>`, а не `div`/`span`.
- Фокус видим при навигации с клавиатуры.

## Проверка

- HTML проверен валидатором W3C — ошибок нет.
- Страница проверена на ширине 360, 768 и 1280 px: горизонтальная прокрутка отсутствует, карточки перестраиваются в 1, 2 и 3 колонки.
- Все ссылки и изображения работают.
